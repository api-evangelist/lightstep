# Lightstep (lightstep)

Lightstep, now ServiceNow Cloud Observability, is a distributed tracing and observability platform that helps teams monitor, debug, and optimize microservice performance. It provides deep visibility into distributed systems using OpenTelemetry-based tracing, metrics, and service health monitoring.

## APIs

### Lightstep API
The Lightstep API (now Cloud Observability API) provides programmatic access to observability data including traces, spans, streams, dashboards, alerting conditions, and service health. It enables teams to manage their observability configuration and query telemetry data programmatically.
