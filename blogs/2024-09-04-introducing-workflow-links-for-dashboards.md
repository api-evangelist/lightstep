You can now add dashboard workflow links to a dashboard or panel that allow you to navigate to another app or another place in Cloud Observability. You can use variables in the link to keep some context of the dashboard when navigating using the value of an attribute currently returned by the query or using the current value(s) of a template variable. For example, you can create a link that creates a notebook with a query on the given service.
